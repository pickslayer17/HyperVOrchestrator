Скрипты создания/настройки VM:

Починить autounattend.xml — локаль, автологон, убрать OOBE экраны
Вынести переменные в конфиг (имя VM, IP, пароли, пути)
Прописать прокси в post-install скрипт
Подключение сети (NATSwitch) в create_vm.ps1

Настройки внутри VM:

Права на диск C для TestUser
Отключить Windows Update автоперезагрузку
Отключить auto-shutdown VM при выключении хоста (Set-VM -AutomaticStopAction Save)
Отключить lock screen timeout
Убрать русский язык (подтягивается с хоста)
Установка .NET SDK 10, FlaUI, рантаймов — через скрипт
Установка софта (Office ODT, Git, Node — когда понадобится)
Обязательно добавить включение всегда в Basic Session. выставить резолюцию 1920*1080

Хост:

Автозапуск proxy.py
Автозапуск rdp_forward.py
(ты сказал сам справишься с хостовой частью)
